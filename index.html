Introduction

This application stores a fixed list of hospitals on a fictional 2D grid. It uses a Brute Force algorithm (Chapter 3) to find the hospital nearest to a point you enter, and Interpolation Search (Chapter 4) to look up a hospital by its ID.

All coordinates are fictional Cartesian values for academic testing. They are not real map locations.

Algorithms

Explanations and complexity analysis.

Brute Force (Chapter 3)

Brute Force solves a problem by checking every possibility directly. Here, the distance from the user's point to every hospital is calculated and the smallest one is kept.

  1. Start with the first hospital as the current nearest hospital.
  2. Calculate the squared distance from the user's point to each hospital.
  3. Compare it with the current minimum distance.
  4. If a smaller distance is found, update the nearest hospital.
  5. If the distances are equal, keep the hospital with the smaller ID.
  6. Repeat until all hospitals have been compared.

Euclidean Distance

The distance between two points (x1, y1) and (x2, y2) is:

d = √((x1 - x2)² + (y1 - y2)²)

Because the square root keeps the same order (a smaller d² always means a smaller d), the program compares the squared distance:

d² = (x1 - x2)² + (y1 - y2)²

The square root is calculated only once, to display the final actual distance.

Closest-Pair Adaptation

The general Closest-Pair problem finds the two closest points among n points. Its brute-force solution checks every pair, which takes O(n²) time. This project is an adaptation: it compares only one user point against n hospitals, so it needs just n distance calculations and runs in O(n) time.

Interpolation Search (Chapter 4)

Interpolation Search works on a sorted array. Instead of always probing the middle, it estimates where the key should be, based on its value:

x = l + ⌊((v - A[l]) × (r - l)) / (A[r] - A[l])⌋

where x = estimated position, l = lower index, r = upper index, v = search key, A = sorted hospital ID array.

  1. Keep the hospital IDs sorted in ascending order.
  2. Calculate x using the formula.
  3. Compare v with A[x].
  4. If they are equal, the hospital is found.
  5. If v is smaller, set r = x - 1.
  6. If v is greater, set l = x + 1.
  7. Repeat until the hospital is found or the range becomes invalid.

The search handles empty ranges, IDs below the minimum, IDs above the maximum, and division by zero (when A[r] = A[l]).

Variable-Size-Decrease

In a variable-size-decrease algorithm, the size of the problem is reduced by a different amount at each step. In Interpolation Search the range l..r shrinks by an amount that depends on where the estimate x lands and on the values in the array, not by a fixed half as in Binary Search.
